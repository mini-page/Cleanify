Features

Everything you need to take control of your files.

🃏

Swipe Sorter

Sort thousands of files with a fun Tinder-style card interface. Keep, delete, move, or skip with a single gesture.

  • Swipe right to keep · left to delete
  • Target folder bar for quick moves
  • Inline video player with speed control
  • Undo any action at any time
  • Summary sheet to review before applying
🔍

Duplicate Finder

Free up gigabytes by eliminating exact copies and visually similar media.

  • Hybrid hashing — size filter + pixel / content hash
  • Visual similarity via dHash & color histograms
  • Configurable strict / balanced / loose thresholds
  • Similarity denial to suppress false positives
  • Background scanning with progress notifications
🧹

Junk Remover

Beyond media — clean empty files, folders, APKs, temp files, and corpse folders.

  • Double-Checker runs multiple passes
  • Auto-Whitelist protects backup paths
  • Clean on boot & scheduled cleaning
  • Blacklist / Whitelist editors with regex
  • Quick Clean — skip scan, apply instantly
📂

Session Setup

Auto-discover media folders, browse by category, and configure every session your way.

  • Auto-discovery with live scanning progress
  • Favorites, System, User folder categories
  • Multi-select & recursive folder selection
  • Search, sort, and pull-to-refresh
  • Mark folders as sorted to hide them later
🎨

Theming

Five theme modes including true-black AMOLED. Material You dynamic colors and accent picker.

  • Light · Dark · Darker · AMOLED
  • Material You wallpaper colors (Android 12+)
  • Curated accent color palette
  • Language: English · Italiano
⚙️

Customization

Every detail configurable — gestures, layout, folder behavior, video defaults, and more.

  • Swipe sensitivity & direction control
  • Configurable swipe-down action
  • Folder name position on cards
  • Export / Import settings & favorites
  • Full-text searchable settings

Changelog

What’s new in recent releases.

v2.6.0— 2026-06-11
Added
  • Native xxHash64 hashing engine — SHA-256 replaced with xxHash64 via C/NDK for ~10x faster hash computation on bulk media scanning.
  • CMake + NDK integration — native code compiled for all target architectures.
  • NativeHasher fallback — pure-Kotlin hashBytes() fallback if native library fails to load.
  • Release keystore for signed release builds.
Changed
  • Duplicate scanning now uses native xxHash64 for full file hashes, partial video hashes, and pixel hashes.
v2.5.0— 2026-06-11
Added
  • Haptic feedback on all destructive actions: swipe, delete, apply changes.
  • In-app update checker with download progress and package installer launch.

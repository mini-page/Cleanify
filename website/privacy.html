🔐 Privacy Policy

Your Privacy is Sacred

Cleanify is built on one principle: your files are yours alone. No data ever leaves your device.

Last updated: June 2025 • Effective: June 2025

📋 Overview

✅

Cleanify collects zero personal data. No analytics, no crash reports, no telemetry, no ads, no accounts. Everything stays on your device.

This Privacy Policy explains how Cleanify handles (or rather, doesn't handle) your information. By using Cleanify, you agree to this policy.

🚫 Information We Do Not Collect

Cleanify does not collect, process, store, or transmit any of the following:

  • Personal information (name, email, phone number)
  • Device identifiers (IMEI, advertising ID, Android ID)
  • Location data (GPS or network-based)
  • Usage analytics or behavioral data
  • Crash reports or diagnostic data
  • Photos, videos, or any media file content
  • Contact names, numbers, or any contact data
  • Purchase or payment information

💾 Local Data Storage

All preferences, scan history, and Recycle Bin data are stored exclusively in local on-device storage using Android DataStore and Room database. This data:

  • Never leaves your device
  • Is not accessible to Cleanify developers
  • Can be cleared by uninstalling the app
  • Can be partially cleared in Settings → Advanced → Reset History

🔒 Permissions Explained

Cleanify requests these Android permissions, each with a specific, limited purpose:

MANAGE_EXTERNAL_STORAGE
Scan, read, move, and delete files across all device directories. Required for all core file-management features.
QUERY_ALL_PACKAGES
Detects leftover data folders from apps you've uninstalled (Corpse Cleaner). No package data is stored or transmitted.
READ_CONTACTS / WRITE_CONTACTS
Only requested when you open Contact Cleaner. Contact data is processed locally only — never transmitted.
KILL_BACKGROUND_PROCESSES
Optional RAM-clearing feature in Empty Cleaner. Uses Android's ActivityManager locally only.
INTERNET
Used only for the optional update checker: queries api.github.com/repos/mini-page/Cleanify/releases/latest. No other network requests are ever made.
RECEIVE_BOOT_COMPLETED
Enables the optional "clean on boot" feature. No data is transmitted.
FOREGROUND_SERVICE / POST_NOTIFICATIONS
Shows progress notifications during background scans. Only active when a scan is running.

🌐 Network Requests

The only network request Cleanify ever makes is the optional, user-triggered update check:

  • https://api.github.com/repos/mini-page/Cleanify/releases/latest

This only runs when you tap "Check for Updates" in Settings → About. No personal or device data is included.

🛡️

All file management features are 100% offline and make zero network requests.

🧒 Children's Privacy

Cleanify does not collect any data from users of any age. Since no data is collected at all, the app is safe and suitable for all ages including children under 13.

🔄 Changes to This Policy

If this Privacy Policy changes (e.g., due to a new feature requiring network access), the change will be announced in the app changelog and this page will be updated. We will never introduce data collection without clearly documenting it first.
